# Security Policy

## Scope

Sleep, My Sweetie is a small local shell utility. It installs one executable in
`/usr/local/lib/sleep-my-sweetie/` and symbolic links in `/usr/local/bin/`.

It does not intentionally collect data, communicate over a network, install a
background service, or run automatically at startup.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's
private vulnerability reporting feature if it is enabled for this repository.
Otherwise, contact the repository owner privately through a channel listed on
their GitHub profile.

Include the affected version, relevant command or file, reproduction steps,
and potential impact.

## Safe use

This program requests a real system power-off. Inspect the source before
installing it, save your work before running it, and use administrative
privileges only when you understand the command being executed.
